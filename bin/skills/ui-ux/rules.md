# Skill: ui-ux-design — rules ringkas

1. Pahami **tujuan user & alur** (user flow) sebelum visual; wireframe kasar dulu bila membantu.
2. **Konsisten** via design system/token (warna, tipografi, spacing, radius, komponen) — jangan ad-hoc per layar.
3. **Hierarki jelas**: satu aksi utama per layar, whitespace cukup, jangan overload.
4. **a11y**: kontras AA, fokus keyboard terlihat, label/`aria`, target sentuh ≥44px.
5. **Interaksi lengkap**: state hover/active/disabled/loading/error + empty-state. Jangan hanya happy path.
6. **Responsif**: uji layar kecil & besar. Verifikasi visual + kontras + fokus sebelum klaim selesai.
